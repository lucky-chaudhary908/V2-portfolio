LUCKY CHAUDHARY — 3D PORTFOLIO V2

RUN
1. Open this folder in VS Code.
2. Right-click index.html -> Open with Live Server.
3. The browser will open the portfolio.

FILES
- index.html = content and sections
- style.css = visual design, responsive layout, 3D styling
- script.js = mouse effects, particles, 3D tilt, social links

EASY EDITS
1. In index.html search for "ADD" to find unfinished education/project fields.
2. Replace the two editable project cards with your future projects.
3. In script.js replace # in SOCIAL_LINKS with your real LinkedIn/GitHub URLs.
4. To change the main green accent, edit --green in style.css.
5. You can change text directly in index.html without touching JavaScript.

This version keeps the supplied CV information and does not invent missing school percentages/years or project details.
